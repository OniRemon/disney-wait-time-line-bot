# アプリの説明

LINEでパーク名やアトラクション名を送ると、Google Apps ScriptがQueue-Timesの待ち時間データを取得し、LINE Messaging APIで返信します。

## コマンド

| コマンド | 動作 |
| --- | --- |
| `ランド`、`TDL` | 東京ディズニーランドの待ち時間 |
| `シー`、`TDS` | 東京ディズニーシーの待ち時間 |
| `両方`、`待ち時間`、`ディズニー` | ディズニーの2パークをまとめて表示 |
| `USJ`、`ユニバ` | USJの待ち時間 |
| `ソアリン`、`マリオカート` など | 3パークからアトラクション名を部分一致で検索 |
| `お気に入り登録 ソアリン` | 一致したアトラクションを登録 |
| `お気に入り削除 ソアリン` | 登録済みのアトラクションを削除 |
| `お気に入り` | 登録したアトラクションの待ち時間 |
| `空いてる` | ディズニーの2パークで20分以下のアトラクション |
| `人気` | ディズニーの2パークのアトラクションを待ち時間の長い順に表示 |

`ランド 空いてる` や `シー 人気` のように、ディズニーのパークを指定することもできます。お気に入りはLINEユーザーごとに保存されます。登録済みのアトラクションの現在情報が得られないときは、その旨を表示します。

## 待ち時間の表示

パーク別のカードには、運営中として返されたアトラクションを待ち時間の長い順に表示します。待ち時間の色分けは20分以下が緑、21〜60分がオレンジ、61分以上が赤です。

USJでは、データ元の更新から15分以内の情報を表示し、取得結果を5分間キャッシュします。ディズニーの取得結果は10分間キャッシュします。営業時間外などに表示できるデータがなければ、待ち時間がない旨を返信します。

[Powered by Queue-Times.com](https://queue-times.com/)

## Apps Scriptへの設定

1. Google Apps Scriptのプロジェクトに、このリポジトリの `.gs` 10ファイルを同名で配置します。
2. Apps Scriptの「プロジェクトの設定」で、スクリプト プロパティ `LINE_CHANNEL_ACCESS_TOKEN` にLINE Messaging APIのチャネルアクセストークンを設定します。トークンはスクリプト プロパティで管理します。
3. Apps Scriptをウェブアプリとしてデプロイします。既存Botの更新では「デプロイを管理」から現在のデプロイを新しいバージョンに更新します。
4. 新規設定の場合は、デプロイしたウェブアプリの `/exec` URLをLINE Messaging APIチャネルのWebhook URLに設定し、Webhookを有効にします。
5. LINEで `USJ` と `両方` を送って返信を確認します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | Webhook受信、コマンド判定、返信処理の呼び出し |
| `Config.gs` | パークIDとLINE返信APIの設定 |
| `LineBot.gs` | LINEへの返信送信 |
| `QueueTimes.gs` | 待ち時間の取得、整形、キャッシュ |
| `FlexMessage.gs` | LINEの待ち時間カード |
| `AttractionMap.gs` | アトラクション名の日本語表示 |
| `AttractionFeature.gs` | 名前検索、20分以下の抽出、ランキング |
| `Favorite.gs` | お気に入りの登録、削除、表示 |
| `Utils.gs` | 日付や待ち時間の表示などの共通処理 |
| `Debug.gs` | デバッグログの保存、表示、削除 |
