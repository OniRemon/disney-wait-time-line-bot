# ディズニー・USJ 待ち時間 LINE Bot

東京ディズニーランド、東京ディズニーシー、ユニバーサル・スタジオ・ジャパンのアトラクション待ち時間をLINEで確認できるBotです。Google Apps Scriptで動作します。

## LINEでの使い方

| 送るメッセージ | 返信内容 |
| --- | --- |
| `ランド` / `シー` | 指定したパークの待ち時間 |
| `両方` | ディズニーランドとディズニーシーの待ち時間 |
| `USJ` / `ユニバ` | ユニバーサル・スタジオ・ジャパンの待ち時間 |
| `マリオカート` | 名前の一部が一致するアトラクション |
| `お気に入り` | 登録したアトラクションの待ち時間 |

設定手順、全コマンドの使い方、ファイル構成は[アプリの説明](docs/app.md)を参照してください。
